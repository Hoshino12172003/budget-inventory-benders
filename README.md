# budget-inventory-benders

Clean research code for robust inventory reconfiguration and product-wise risk-budget decomposed Benders.

The formal E1–E7 protocol is documented in [docs/formal_experiment_protocol.md](docs/formal_experiment_protocol.md). It is currently blocked and every formal configuration remains unauthorized; see [experiments/README.md](experiments/README.md) for read-only audit commands.

This repository is a selective, history-free restructuring of the current paper code. The initial `main` branch contains only the project skeleton; model specifications, data audits, and tests are developed through focused pull requests.

No results or implementation history from the legacy Benders repository are copied here.
