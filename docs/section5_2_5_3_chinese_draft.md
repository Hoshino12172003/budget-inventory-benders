# 5.2 Economic effects of robust inventory reconfiguration

为识别稳健库存重配置的实际作用，本节将规范化现行配置与经认证的稳健配置固定在一期，不再优化仓库启用和库存配置决策，并在完全相同的需求扰动清单上重新评价二阶段配送、缺货和服务超限。评价覆盖八个 Renault 数据派生案例；每个政策使用 Gamma=2 下预先冻结的 4,657 个情景。由于这些情景没有概率权重，后文的“情景集合均值”仅指枚举集合上的等权算术均值，而非需求分布意义上的期望值。

结果首先表明，稳健重配置的价值不能简单概括为减少缺货单位数。在四个发生实质库存调整的案例中，稳健配置的名义、情景集合均值和最大总缺货量均略高于现行配置；另外四个案例的两种配置结果在数值容差内一致。因此，现有证据不支持“稳健重配置系统性缓解物理缺货”的结论。服务超限量呈现相同方向：实质调整案例有所增加，而未调整案例基本不变。

然而，缺货的经济损失与缺货总量并不保持同一方向。在上述四个实质调整案例中，稳健配置的名义、集合均值和最大缺货惩罚成本均下降。其原因不是总缺货量减少，而是库存位置和产品结构的改变使未满足需求转移到单位损失较低的需求分量。换言之，重配置降低的是缺货的经济暴露，而非缺货的物理规模。这一区分对于评价有限库存条件下的韧性尤为重要：当总供给不足以消除缺货时，决策仍可以通过改变缺货构成限制经济后果。

经济追索指标进一步揭示了名义效率与不利情景保护之间的权衡。在四个实质重配置案例中，最大经济追索成本均下降，八案例平均相对变化为 -0.0735%；与此同时，这四个案例的名义经济追索成本均上升，八案例平均相对变化为 +0.1001%。其余四例的差异处于 1e-6 数值容差内。该结果表明，稳健配置以小幅正常状态代价换取小幅最坏经济损失保护。这里的最大经济追索成本分别在各政策的 4,657 个情景上求取；最大总缺货、最大服务超限和最大缺货惩罚使用各自的实现情景，未将经济成本最坏情景替代为其他指标的最坏情景。

成本分解说明上述权衡来自多个分项的共同变化。实质调整案例的运输成本和缺货惩罚成本下降，但服务惩罚相关的超限量增加，因而不能由任一单项成本方向推断总追索方向。一期重配置支出则来自稳健政策的原始认证记录：210129、210202、210323 和 210330 分别发生约 248.10、478.82、89.14 和 139.23 成本单位的重配置支出，其余案例在容差内为零。该支出不属于本节固定政策评价的二阶段追索成本，因此不与追索差额机械相加为“总成本改善”。

总体而言，稳健库存重配置在本组案例中的主要贡献是限制不利需求组合下的经济损失，而不是全面改善缺货量或服务表现。这一结果为本文使用“面向需求不确定性的经济韧性”提供了可操作定义：在给定扰动集合内控制经济损失恶化，同时承认有限库存下的服务权衡和正常状态代价。

# 5.3 Sensitivity and boundary conditions of inventory resilience

上一节识别了固定政策比较中的基准效应，本节复用五类既有正式敏感性实验，考察该经济保护受到哪些资源和参数条件约束。需要强调的是，E3–E7 在各参数单元重新优化一期配置，并按该单元的不确定集评价；它们不同于上一节在共同情景集合上固定 Existing 与 Robust 的设计。因此，本节提供参数机制和边界条件的补充证据，而不把跨实验变化直接归因于上一节的某一政策差异。

财务预算敏感性 E3 在 Gamma=2、重配置摩擦系数为 0.05 时改变预算倍数。八案例结果显示，预算从基准的 0.8 倍提高到 1.2 倍时，平均归一化目标由 1.010323 降至 0.999751，平均重配置强度由 0.368066 降至 0.010384。较紧预算既提高经济成本，也迫使方案更大幅度偏离现行库存；当预算扩展到基准的 1.0–1.1 倍附近后，多数收益趋于平台。该平台只对应离散测试网格，不能解释为企业的普遍最优预算阈值。

不确定性预算敏感性 E4 将 Gamma 从 0 增至 4，同时重新优化相应稳健问题。平均归一化目标由 1.0000 增至 1.1322，平均重配置强度由零增至 0.1245，但案例触发时间不同：部分网络在 Gamma=1 即调整，部分到 Gamma=4 才调整，另有三个案例在整个网格内保持基准库存。这表明经济暴露随风险集合扩大而增加，但调整需求具有明显的网络异质性。由于 Gamma 同时改变规划问题和最坏评价集合，该结果不能解释为在同一压力测试下仅更换库存配置的纯效果。

重配置摩擦敏感性 E5 在预算倍数为 1、Gamma=2 时改变 `lambda_R`。从 0 到 0.20，平均目标仅恶化约 0.0747%，而重配置强度并不单调下降。摩擦既直接提高库存移动成本，也通过共享财务预算挤占库存支出，促使方案改变调整对象、集中度和规模。因而，摩擦更适合解释为塑造调整组成和预算负担的参数，而不是对重配置量施加简单上限。

两个交互实验进一步说明边界机制。E6 的预算×风险网格显示，紧预算下八个案例在 Gamma=0 已全部发生实质调整，平均重配置强度在 Gamma=0、2、4 均约为 0.3681；风险提高仍推升经济暴露，但难以进一步提高总体调整幅度。相比之下，基准和宽松预算下的配置会随 Gamma 逐步响应。该现象说明财务稀缺可能使调整提前饱和，且决策层面的交互显著强于经济结果层面的交互。E7 的风险×摩擦网格则显示，Gamma=4 时平均重配置强度由低摩擦下的 38.10% 降至高摩擦下的 3.46%，调整也更加集中于较少的仓库—产品坐标；但八个案例在离散 Gamma 网格上的首次实质调整位置不随三个摩擦水平改变。摩擦由此主要影响风险响应的强度和组成，而非测试网格中的广延触发集合。

五类敏感性证据共同限定了上一节的经济保护结论。稳健重配置的价值在风险暴露增加时更具相关性，但其实现形式取决于财务能力和移动摩擦：紧预算可能迫使系统预先进行大幅调整甚至缩减规划期仓库网络，高摩擦则抑制并集中高风险下的库存移动。与此同时，经济目标的变化通常小于配置决策的变化，且服务指标并不一致改善。这说明企业不应以单一缺货量或统一调整幅度评价库存韧性，而应同时考察预算余量、风险范围、移动成本以及产品层面的缺货损失权重。

本节结论仍受证据边界约束。所有结果来自八个 Renault 数据派生案例和离散参数网格，不构成统计显著性、因果效应或连续阈值证明。当前仓库 checkout 保存了 E3–E7 的正式授权、最终审计和派生表，但未携带审计所对应的展开原始结果 root 与 frozen ZIP；因此论文复现包发布前仍需恢复这些已存在的归档并按记录哈希核验。本研究也未测量恢复时间、客户流失或供应中断后的恢复过程，故“经济韧性”应始终限定为给定需求不确定集合内对经济损失恶化的控制。
